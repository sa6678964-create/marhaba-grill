# Marhaba Grill - Production Deployment Guide\n\n## Architecture Overview\n\n```\nFrontend (marhaba_online_ordering_app/)\n  ├─ www.marhaba-grill.com (Vercel)\n  └─ Calls → api.marhaba-grill.com\n\nBackend (api/)\n  ├─ Vercel Serverless Functions\n  └─ api.marhaba-grill.com/api/*\n\nAdmin Panel (admin/)\n  └─ admin.marhaba-grill.com (Vercel)\n\nDatabase\n  └─ Supabase PostgreSQL (Production)\n```\n\n## Environment Setup\n\n### 1. Supabase Project\n- Create project at https://supabase.com\n- Run migrations: `psql $DATABASE_URL -f migrations/0001_init.sql`\n- Collect credentials:\n  - `SUPABASE_URL`\n  - `SUPABASE_SERVICE_ROLE_KEY`\n  - `SUPABASE_ANON_KEY`\n\n### 2. Stripe Account\n- Create account at https://stripe.com\n- Get TEST MODE keys:\n  - `STRIPE_SECRET_KEY` (sk_test_...)\n  - `STRIPE_WEBHOOK_SECRET` (whsec_test_...)\n  - `STRIPE_PUBLISHABLE_KEY` (pk_test_...)\n\n### 3. Generate JWT Secret\n```bash\nnode -e \"console.log(require('crypto').randomBytes(32).toString('hex'))\"\n# Copy output and use as ADMIN_JWT_SECRET\n```\n\n## GitHub Repository Setup\n\n1. **Branch Structure**\n   - `main` → Production\n   - `backend/supabase-stripe` → Staging\n\n2. **Secret Configuration**\n   - Go to: Settings → Secrets and variables → Actions\n   - Add secrets (never commit to .env):\n     - `SUPABASE_SERVICE_ROLE_KEY`\n     - `STRIPE_SECRET_KEY`\n     - `STRIPE_WEBHOOK_SECRET`\n     - `ADMIN_JWT_SECRET`\n\n## Vercel Deployment\n\n### Create Vercel Projects\n\n**Frontend Project** (www.marhaba-grill.com)\n```bash\nvercel link  # Link frontend directory\nvercel env add SUPABASE_URL\nvercel env add SUPABASE_ANON_KEY\nvercel env add API_URL https://api.marhaba-grill.com\n```\n\n**Backend API Project** (api.marhaba-grill.com)\n```bash\ncd api/  # or backend/supabase-stripe\nvercel link\nvercel env add SUPABASE_URL\nvercel env add SUPABASE_SERVICE_ROLE_KEY\nvercel env add STRIPE_SECRET_KEY\nvercel env add STRIPE_WEBHOOK_SECRET\nvercel env add ADMIN_JWT_SECRET\n```\n\n### Environment Variables in Vercel\n\n**Go to: Project Settings → Environment Variables**\n\n#### Staging Deployment (backend/supabase-stripe)\n```\nSUPABASE_URL=https://your-project.supabase.co\nSUPABASE_SERVICE_ROLE_KEY=****[paste from Supabase]\nSUPABASE_ANON_KEY=****[paste from Supabase]\nSTRIPE_SECRET_KEY=sk_test_****[paste from Stripe Dashboard]\nSTRIPE_WEBHOOK_SECRET=whsec_test_****[paste from Stripe Dashboard]\nADMIN_JWT_SECRET=****[paste generated secret]\nDEFAULT_DELIVERY_FEE=3.5\nCURRENCY=eur\nLOG_LEVEL=debug\n```\n\n#### Production Deployment (main)\n```\n[Same as above, but:\n- STRIPE_SECRET_KEY → sk_live_**** (after approval)\n- STRIPE_WEBHOOK_SECRET → whsec_live_**** (after approval)\n- LOG_LEVEL=info (not debug)\n]\n```\n\n## Stripe Webhook Configuration\n\n### Test Mode (Staging)\n1. Go to: https://dashboard.stripe.com/test/webhooks\n2. Click \"Add endpoint\"\n3. Endpoint URL: `https://api.marhaba-grill.com/api/webhooks-stripe`\n4. Events to send:\n   - `payment_intent.succeeded`\n   - `payment_intent.payment_failed`\n   - `charge.refunded`\n5. Copy Signing secret → `STRIPE_WEBHOOK_SECRET`\n\n### Live Mode (Production)\n- Repeat above after going live\n- Use `https://api.marhaba-grill.com/api/webhooks-stripe` (same URL)\n- Different signing secret for live mode\n\n## Database Backup & Restore\n\n### Create Backup\n```bash\nexport DATABASE_URL=\"postgresql://user:pass@host:5432/marhaba\"\n./scripts/backup-restore.sh backup\n# Output: backups/marhaba_backup_20240814_120000.sql\n```\n\n### Restore from Backup\n```bash\n./scripts/backup-restore.sh restore\n# Confirms before proceeding\n```\n\n### Test Restore Procedure\n```bash\n# Create test database\ncreatedb marhaba_test\n\n# Set test URL\nexport TEST_DATABASE_URL=\"postgresql://user:pass@localhost:5432/marhaba_test\"\n\n# Run test\n./scripts/backup-restore.sh test\n```\n\n## CI/CD Pipeline\n\n### GitHub Actions Workflows\n\n**.github/workflows/secret-scan.yml**\n- Scans for hardcoded secrets\n- Verifies .env is in .gitignore\n- Blocks commits with credentials\n\n**.github/workflows/deploy.yml**\n- Validates environment variables\n- Runs tests on all branches\n- Auto-deploys staging from `backend/supabase-stripe`\n- Auto-deploys production from `main`\n\n## Domain Configuration (DNS)\n\n### marhaba-grill.com\n\n**Vercel Default**\n```\nwww CNAME cname.vercel-dns.com\n```\n\n**Custom Domain Setup**\n1. Go to Vercel Project Settings → Domains\n2. Add domain: `marhaba-grill.com`\n3. Add subdomain: `www.marhaba-grill.com`\n4. Add API subdomain: `api.marhaba-grill.com`\n5. Vercel provides DNS records to add to registrar\n\n**DNS Records at Registrar**\n```\nwww.marhaba-grill.com A 76.76.19.161 (example, Vercel will provide actual IP)\napi.marhaba-grill.com CNAME cname-api.vercel-dns.com\n```\n\n## Security Checklist\n\n- [ ] All secrets in Vercel Environment Variables (not in .env)\n- [ ] .env and .env.local in .gitignore\n- [ ] GitHub Actions secret-scan passes\n- [ ] HTTPS enabled on all domains\n- [ ] Stripe webhook signing verified\n- [ ] Admin JWT secret is 32+ characters\n- [ ] Rate limiting configured\n- [ ] Database backups automated\n- [ ] CORS configured for www.marhaba-grill.com only\n- [ ] CSP headers enabled\n- [ ] HSTS enabled\n\n## Monitoring & Logs\n\n### Vercel\n- https://vercel.com/dashboard → Deployments → Logs\n\n### Supabase\n- https://supabase.com → Project → Logs\n\n### Stripe\n- https://dashboard.stripe.com/logs\n\n## Rollback Procedure\n\n### Quick Rollback (Vercel)\n1.
